# Visual resources — Mundo Awoo, Barrio edition

- `barrio.webp`: adapted and optimized from the user's existing `club-castro-frontend/public/medellin_comuna_street.png` project asset. Illustrative neighborhood scene; not a claim of a specific street's exact appearance.
- `crowd.webp`: adapted and optimized from the user's existing `club-castro-frontend/public/reggaeton_stage_crowd.png` project asset.
- `el-cantante-del-ghetto.jpg`: official album artwork linked from https://ryancastrooficial.lnk.to/ECDGH — https://linkstorage.linkfire.com/medialinks/images/0b790e33-47f9-4d56-afe5-698429f0d294/artwork-440x440.jpg . Used to identify the album in a link to its official listening page. Artwork remains the property of its rights holders.
- `grain.svg`, `/lobo.svg` (legacy), `/piezas/poncho.svg`, `/piezas/lentes.svg`, `/piezas/gorra.svg`, `/piezas/gorra-espalda.svg`: custom vector artwork for this interface. Existing asset paths remain compatible; placement uses the human avatar coordinate system.
- Typefaces: Barlow Condensed ExtraBold (SIL OFL), Permanent Marker (Apache 2.0), downloaded from the Google Fonts repository; license files accompany the fonts in `/public/fonts`. Fonts are served locally through `next/font/local`.

Design reference: Ryan Castro, El Cantante del Ghetto — https://www.sonymusiclatin.com/artists/ryan-castro/ . The interface does not claim official artist affiliation.

- `/avatar/ryan-castro.webp`: custom character sprite generated with built-in ImageGen using the user’s jacket photographs and an artist portrait as references. Generation prompt and provenance: `docs/avatar-ryan.md`.
